Payment Provider: NEGDI

Mongolian card and QPay payments in Odoo - free and open source (LGPL-3)

Take payments in Mongolian tugrik through the NEGDI e-commerce gateway: bank cards with 3-D Secure, and QPay. The customer pays on NEGDI's page and comes back to your Odoo, where the order is confirmed the way any other payment provider confirms it.

Cards (3-D Secure)

The card is authorised on the issuing bank's own page. Card numbers never reach your Odoo and are never stored by this module.

QPay

The customer scans the QR code in their banking app. The same transaction flow, the same confirmation.

What it does

  • Standard Odoo redirect flow: it works with eCommerce, invoices and payment links, with no per-shop code.
  • Every gateway response is verified against NEGDI's public key before it is trusted.
  • A scheduled job settles payments whose confirmation arrives late or not at all, so a customer who closes the browser is not left unconfirmed.
  • Refunds are offered only when NEGDI allows the transaction to be reversed.
  • Mongolian translation included; the checkout-visible messages read naturally in Mongolian.

Before you install

You need a merchant account with NEGDI - they issue the username, password and terminal ID you enter in Odoo. This module does not create that account for you. Contact NEGDI at hello@negdi.mn.

Requirements

Odoo 18, on your own server or Odoo.sh. Odoo Online cannot install custom modules.
